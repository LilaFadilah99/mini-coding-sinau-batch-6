## Starter Project

Folder `starter/` berisi struktur kosong yang bisa di-copy peserta sebagai titik awal:

```
starter/
├── PROJECT_BRIEF.md   (rangkuman hasil planning Day 1 — wajib dibaca AI)
├── index.html         (skeleton minimal dengan link Google Fonts + CSS)
└── css/
    └── style.css      (reset minimal saja)
```

Copy folder ini ke folder kerja masing-masing peserta sebelum mulai praktik.

### Tentang `PROJECT_BRIEF.md`

File ini adalah **output fase Planning di Day 1** yang berisi visi, target user, fitur MVP, design system (warna, font, shadow), wireframe, dan aturan kerja dengan AI. Setiap kali peserta prompt AI di Day 2+, file ini wajib **dilampirkan** sebagai konteks utama. Ini bikin prompt selanjutnya jadi lebih ringkas dan konsisten — AI tidak perlu "ditebak" warna/spacing-nya tiap kali.
